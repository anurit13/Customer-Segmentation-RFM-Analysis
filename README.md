\# Customer Segmentation \& RFM Analysis



\## Overview



This project performs customer segmentation using the RFM (Recency, Frequency, Monetary) framework on retail transaction data.



The objective is to identify valuable customers, detect churn risk, and provide data-driven marketing recommendations.



\## Tools



\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Plotly



\## Key Analysis



\- Data Cleaning

\- Profit Analysis

\- Customer Segmentation

\- Revenue Analysis

\- Channel Performance

\- Category Performance

\- Sales Trend Analysis



\## Key Findings



\- Champions and Loyal customers generated the highest revenue.

\- Consumer channel contributed over 50% of revenue.

\- Technology products generated the highest sales.

\- Several customer groups showed churn risk and require retention strategies.



\## Business Recommendations



\- Strengthen loyalty programs for high-value customers.

\- Improve retention campaigns for At Risk customers.

\- Optimize marketing investments based on customer segments.
